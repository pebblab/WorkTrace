# Quick Start

1. Extract the download into a folder you own, such as Documents.
2. Double-click LivingJournal.desktop and allow launching if Linux asks. If nothing opens, open a terminal in the extracted folder and type `bash launch.sh`.
3. Your browser opens the local journal. No account is needed.
4. Open the project selector and choose **Create project**. Give it a name; category is optional.
5. Select the project and click **New Entry**.
6. Write a short note in the large text area, then Save. The current date/project are automatic.

Use Search at the top. `cat` also finds catch and concatenate; `"cat"` finds only the word; `"stress pattern"` finds the exact phrase with normal whitespace. Dates/project filters can narrow results.

Click Edit / files to change text, summary, headline or project. Exclude hides an entry without deleting it; check Excluded entries to restore it.

Imported conversations and agent drafts require human review. Approve historical entries in Edit before archiving. Manually written entries are approved when saved.

To close the server, open a terminal in the folder and run `bash launch.sh --stop`. Closing the browser tab alone does not stop it.
